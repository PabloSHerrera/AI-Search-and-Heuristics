# AI Search and Heuristics

Maze-solving with classical AI search algorithms. The project reads mazes from text files, models them as graphs, and compares uninformed and heuristic-guided search strategies in terms of path quality and efficiency.

## Highlights

- Maze parsing from text files into a graph/grid representation
- Implementation of uninformed and informed (heuristic) search algorithms
- Comparison of algorithms by path length and nodes explored
- Tested on three mazes of increasing complexity

## Repository Structure

| File | Description |
|---|---|
| `Proyecto_1_Codigo.ipynb` | Notebook with implementation and results |
| `Proyecto 1 codigo.py` | Standalone Python script version |
| `Laberinto1.txt` – `Laberinto3.txt` | Test mazes |

## Tech Stack

Python · Jupyter Notebook

## How to Run

1. Clone the repository:

```bash
   git clone https://github.com/PabloSHerrera/AI-Search-and-Heuristics.git
   cd AI-Search-and-Heuristics
```
2. Run the script or open the notebook:

```bash
   python "Proyecto 1 codigo.py"
```
